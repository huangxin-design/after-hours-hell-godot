# 每日更新规则

目标节奏为北京时间每天 20:00，由维护者的独立调度管理；本仓库不创建重复定时器，
也不运行付费生成、渲染、游戏制作或无人值守的全工作区同步。

1. 读取紧凑交付记录，寻找真实交付的可复用 Skill、工具脚本或工作流，以及相关修复。
2. 核对实际文件、依赖、入口、版本和验证证据，审核事实、隐私与再分发权利。
3. 有实质变化时更新技术索引、用法、验证范围和简洁版本记录；保留首版，不拷贝内部原文。
4. 运行公开验证器和发布目录敏感信息检查，复核本次准确文件清单与差异。
5. 仅暂存白名单内的明确文件，提交并推送；核对远端提交和公开元数据。

**没有实质变化就不提交。** 仅时间戳改变、后台进度百分比或重复的状态检查不构成
更新理由。未经审核的新资产、路径和文件不会自动进入仓库。失败时保留错误结果，
不重复创建仓库或强制推送。每日检查不等于每天必有新功能完成。

单纯素材生成完成、制作进度变化或新的过程图不自动构成工具仓库更新。完整调试日记、
前后对比和制作回忆册由项目网页维护；这里补充已核验的案例链接和复用所需技术摘要。
案例不得把 Blender 候选或后台检查通过写成游戏内、设备或打印验收完成。

当前尚无可安装 Skill 或 MCP 服务。正式制作 Skill 时使用 skill-creator，明确输入、
输出、依赖和权限边界，并在真实任务中验证后再标记交付；不为每日更新硬凑功能。
