# 每日更新规则

目标节奏为北京时间每天 20:00，由维护者的独立调度管理；本仓库不创建重复定时器，
也不运行付费生成、渲染、游戏制作或无人值守的全工作区同步。

1. 读取制作线的紧凑交付记录，仅检查实际版本、文件哈希与验收结果变化。
2. 在私有工作区形成候选差异，审核事实、隐私与再分发权利。
3. 有值得公开的变化时更新状态、来源索引与当日开发日志；不拷贝内部原文。
4. 运行公开验证器和发布目录敏感信息检查，复核本次准确文件清单与差异。
5. 仅暂存白名单内的明确文件，提交并推送；核对远端提交和公开元数据。

**没有实质变化就不提交。** 仅时间戳改变、后台进度百分比或重复的状态检查不构成
更新理由。未经审核的新资产、路径和文件不会自动进入仓库。失败时保留错误结果，
不重复创建仓库或强制推送。每日检查不等于每天必有新功能完成。
