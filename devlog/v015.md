# v015 · 选好同事，再出发

Windows 最终试玩版用《下班，走这边》带玩家走到电梯门口。选锅仔，会先看到举锅反弹；选小默，会看到替身留下来吸引火力；选椅哥，会看到椅背放平、弹丸掠过。每段影片可以看完，也可以按空格跳过，随后以所选角色进入第一层。

本版制作记录覆盖三位角色各一次自然播完和一次空格跳过，共六组，分布在 720p 窗口和 4K 全屏两种模式。随 Windows 包一同公开的源码可以查看影片转场、输入处理和角色技能的实现。
